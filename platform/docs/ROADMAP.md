# rs-face Platform 路线图

> 愿景:收敛于一个**高效、性能最强、效果最好**的人脸识别开源平台——
> 核心套件(core + SDK)+ 生态外围(Web/Client、标注、自迭代、可视化)。
> 原则:core 永远零依赖、独立发布;平台围绕 core 做工程化与数据闭环。

## v0.1 —— 平台 MVP(本版本,已实现)

- [x] core 即 SDK:平台以 path 依赖消费 `rs-face`,内核零改动;
- [x] Web 管理端:图片 / 视频 / 直播流三种识别入口;
- [x] 原始 vs 识别结果对比(双栏;视频播放同步;直播流双帧);
- [x] 人脸时间轴:按出现先后排序、含时间点与置信度、点击跳转;
- [x] 任务引擎 + REST API + SSE 实时事件;
- [x] rustfs(S3 兼容)存储:原始媒体/原始帧/标注帧/人脸裁剪;
- [x] Docker 一键部署(rustfs + server);
- [x] 方案文档(PLATFORM_DESIGN.md)与本文档。

## v0.2 —— 持久化与工程化

- [ ] 任务元数据落库(SQLite/PG),服务重启可恢复任务历史;
- [ ] 任务队列与并发控制(多任务限流、优先级);
- [ ] 接入 core 多线程 `Pipeline`(每任务 N worker,充分发挥多核);
- [ ] 检测参数(级联选择 Haar/CNN、min_size、阈值)前端可调,按任务保存;
- [ ] 鉴权:API token + 多用户;S3 预签名直传;
- [ ] Client SDK 首发:Rust crate 模板 + CLI(`rsface scan video.mp4 --json`)。

## v0.3 —— 标注闭环(错误数据标注)

- [ ] 时间轴卡片上直接标注:真脸/误检/漏检(画框补标);
- [ ] `datasets/` S3 命名空间:标注样本(裁剪图 + 标签 + 来源任务);
- [ ] 标注集导出:训练/验证切分,格式对齐 core `cnn_train` 输入;
- [ ] 难例挖掘:按置信度排序的边界样本优先呈现给标注者。

## v0.4 —— 算法自迭代(AI 运维)

- [ ] 训练管道:`datasets/ -> cnn_train -> models/{version}/`;
- [ ] 评测集 + 自动回归:`benchmarks/` 存每版 precision/recall/fps;
- [ ] **前后效果比对视图**:同一批数据跑新旧两版模型,结果并排、差异高亮;
- [ ] 灰度发布:新权重先在影子任务上运行,指标达标才切换默认;
- [ ] AI 运维看板:准确率/耗时趋势、失败任务归因、资源水位。

## v1.0 —— 开源发布

- [ ] Client 端:桌面 GUI / 边缘设备(Jetson)离线包;
- [ ] GPU(OpenCL)检测路径在平台内可选启用;
- [ ] 完整文档站、示例库、benchmark 基准页;
- [ ] 社区治理:贡献指南、语义化版本、发布流程。

## 指导原则

1. **效果优先**:一切自迭代以"人脸识别准确率最高"为北极星指标;
2. **数据即资产**:标注、模型、评测全部进 S3,可追溯、可复现;
3. **内核与平台解耦**:core 不感知平台;平台通过 SDK 与数据资产驱动内核演进;
4. **每一步可回滚**:模型版本化 + 评测基线,保证"优化"不退化。
