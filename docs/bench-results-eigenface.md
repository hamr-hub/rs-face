# Eigenfaces zero-dependency recogniser — measured accuracy

crops: `out/lbph/crops` (21 identities, 77 crops)

## Protocol

Strict leave-one-out: for each probe the PCA model is **retrained** on the other n−1 crops (Jacobi eigendecomposition of the Gram matrix; crop size and retained eigenvalue energy vary per row). Pair distances are directed (probe vs gallery member; one observation per unordered pair); the gallery endpoint is a training point, so FAR/FRR below is mildly optimistic compared with a probe on unseen data. **LOO rank-1 is the primary metric** — there the probe itself is never in the model. Configurations rank by LOO rank-1, then margin.
